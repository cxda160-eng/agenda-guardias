Pasar las guardias al calendario del celular

Descargá un archivo con tus turnos y abrilo en el celular o la compu para sumarlos a tu calendario. Las guardias traen aviso la noche anterior y 1 hora antes. El archivo no se actualiza solo: cuando cargues guardias nuevas, descargalo otra vez desde la fecha que te falte.

Cómo abrirlo

  1. iPhone / iPad: tocá el archivo descargado → Agregar todo.
  2. Google Calendar: desde la computadora, en calendar.google.com → ⚙ Configuración → Importar y exportar → elegí el archivo → Importar.
  3. Android sin compu: abrí el archivo desde Descargas y elegí Google Calendar.

Si importás dos veces el mismo turno, algunos calendarios lo duplican: elegí “Desde” a partir de lo nuevo.
